# Afsal DevOps Portfolio

A responsive DevOps learning portfolio using HTML, CSS and a little JavaScript.

## Design
Dark navy background with blue and cyan gradients, responsive layout and terminal-inspired hero section.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design

## Privacy
No email address, phone number or LinkedIn details are displayed. The contact section links only to the public GitHub profile and portfolio repository.

## Before publishing
Check the education section and update the college name if you want it shown. Add only certificates and projects you have actually completed.

## Publish with GitHub Pages
1. Open `afsalazeez761-arch/devops-portfolio`.
2. Upload/replace `index.html` and `style.css` in the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After deployment, open `https://afsalazeez761-arch.github.io/devops-portfolio/`.
